## Confirmed Gaps

### ARCHITECTURE GAP

- Reviewed platform tenant-lifecycle and subscription plan-scheduling mutations persist the state change, platform audit record, and outbox event in one PostgreSQL transaction. PostgreSQL integration coverage verifies rollback on persistence failures.
- This transactional guarantee is scoped to the reviewed operations; do not infer it for unrelated or future mutations without verifying their service implementation and tests.

### OPERATIONAL GAP

- No retention, archive, export, or external immutable/WORM storage policy is defined for platform audit records.
- Actor display names/emails are not joined into the platform response; the UI shows authoritative actor IDs only.

### BACKEND CONTRACT GAP

- No date-range filtering, cursor pagination, or bulk export contract exists.
- Read access itself is not audited; ordinary audit-log viewing remains intentionally read-only and unaudited.

### FRONTEND GAP

- Platform audit UI supports only backend-provided action/resource filters and pagination. Tenant audit records are displayed separately in the permission-gated ERP audit-log page; the platform UI never queries tenant audit records. No audit mutation controls are provided.

### REALTIME INFRASTRUCTURE GAP

- Platform audit records are request-time query data; no realtime audit stream is exposed.

### TEST INFRASTRUCTURE GAP

- PostgreSQL integration coverage verifies atomicity and immutable audit persistence for reviewed mutations. Dedicated platform audit HTTP E2E coverage and frontend component test runners for platform/tenant audit pages are not configured.

## Scope and Security

- `AuditLog` remains tenant-scoped and is not queried by `/platform/audit-logs`.
- `PlatformAuditLog` is global, append-only, guarded by `super-admin.read`, and never accepts actor identity or platform scope from the browser.
- PostgreSQL triggers reject updates and deletes for platform audit records.
- Metadata is generated by backend-controlled platform mutations; raw requests, tokens, credentials, and full database snapshots are not stored.
